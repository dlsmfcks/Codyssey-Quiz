# 기능 테스트 결과

## 테스트 환경
- Windows / WSL Ubuntu
- Python 3.14.4
- 실행 명령: `python3 main.py`

## 테스트 결과

| 테스트 항목 | 결과 |
|---|---|
| 메뉴 출력 | 정상 |
| 기본 퀴즈 7개 출력 | 정상 |
| 퀴즈 정답·오답 판정 | 정상 |
| 점수 계산 (6/7, 86점) | 정상 |
| 퀴즈 추가 및 삭제 | 정상 |
| 최고 점수 확인 | 정상 |
| 빈 입력 및 잘못된 숫자 처리 | 정상 |
| 프로그램 종료 | 정상 |

주요 기능을 실행하여 정상 동작을 확인했다.
