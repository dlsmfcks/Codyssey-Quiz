# Codyssey - 상식 퀴즈 게임

## 1. 프로젝트 소개

Codyssey 미션 2에서 Python으로 터미널 기반의 상식 퀴즈 게임을 구현했다.

사용자는 메뉴에서 퀴즈를 풀거나 새로운 문제를 추가하거나 제거하고, 등록된 문제 목록과 최고 점수를 확인할 수 있다. 퀴즈와 최고 점수는 JSON 파일에 저장하여 프로그램을 종료한 후 다시 실행해도 유지되도록 했다.

### 퀴즈 주제 선정 이유

퀴즈 주제는 역사, 과학, 경제, 컴퓨터 등 다양한 분야의 일반 상식으로 선정했다.

특정 분야에 대한 전문 지식이 없어도 참여할 수 있도록 문제를 구성했으며, 새로운 문제를 직접 추가할 수 있도록 하여 다양한 주제로 확장할 수 있게 했다.

기본 퀴즈는 7개이며, 각 문제는 선택지 4개와 정답 번호로 구성했다.

| 구분 | 환경 |

| 데이터 저장 | JSON (UTF-8) |

Python 표준 라이브러리인 `json`, `random`, `pathlib`을 사용했으며 별도의 외부 라이브러리는 사용하지 않았다.

## 3. 실행 방법

### Python 버전 확인

Python 3.10 이상이 필요하다.

```bash
python3 --version
```

### 프로그램 실행

프로젝트 폴더에서 다음 명령어를 실행한다.

```bash
python3 main.py
```

실행하면 다음과 같은 메뉴가 출력된다.

```text
===========================================================
                    📖 상식 퀴즈 게임 🎯
===========================================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 퀴즈 삭제
6. 종료
===========================================================
선택:
```

원하는 메뉴 번호를 입력하여 기능을 실행할 수 있으며, 6번을 선택하면 프로그램이 종료된다.

## 4. 주요 기능

### 4.1 퀴즈 풀기

- 등록된 퀴즈를 출제하고 사용자에게 정답 번호를 입력받는다.
- 각 문제의 정답 또는 오답 여부를 출력한다.
- 모든 문제를 풀면 정답 개수와 100점 만점 기준 점수를 표시한다.
- 기존 최고 점수보다 높은 점수를 획득하면 최고 점수를 갱신한다.
- 등록된 문제가 없으면 안내 메시지를 출력한다.

### 4.2 랜덤 출제 (보너스)

- `random.shuffle()`을 이용하여 문제 출제 순서를 무작위로 섞는다.
- 원본 퀴즈 목록을 복사한 뒤 순서를 섞어 저장된 문제 순서에는 영향을 주지 않도록 했다.

### 4.3 퀴즈 추가

- 문제 내용과 선택지 4개를 입력받는다.
- 정답 번호는 1~4 사이의 숫자로 입력받는다.
- 새로 등록된 문제는 퀴즈 목록에 추가하고 JSON 파일에 저장한다.

### 4.4 퀴즈 목록

- 현재 등록된 퀴즈의 개수와 문제 목록을 출력한다.
- 등록된 퀴즈가 없는 경우 안내 메시지를 출력한다.

### 4.5 점수 확인

- 지금까지 기록한 최고 점수를 확인한다.
- 퀴즈를 한 번도 풀지 않은 경우 별도의 안내 메시지를 출력한다.
- 최고 점수는 JSON 파일에 저장되어 재실행 후에도 유지된다.

### 4.6 퀴즈 삭제 (보너스)

- 현재 등록된 퀴즈 목록을 출력한다.
- 사용자가 입력한 번호에 해당하는 문제를 삭제한다.
- 0번을 입력하면 삭제를 취소할 수 있다.
- 삭제된 결과를 JSON 파일에 반영한다.

### 4.7 입력 및 예외 처리

- 입력값의 앞뒤 공백을 제거한다.
- 숫자가 아닌 입력, 빈 입력, 허용 범위를 벗어난 숫자에 대해 재입력을 요청한다.
- Ctrl+C 또는 EOF 입력이 발생하면 데이터 저장을 시도하고 프로그램을 종료한다.
- 저장 파일이 없으면 기본 퀴즈를 생성한다.
- 저장 파일이 손상되거나 데이터 형식이 잘못된 경우 기본 데이터로 초기화한다.

codyssey-quiz/

| 파일 | 설명 |
|---|---|
| `main.py` | QuizGame 객체 생성 및 프로그램 실행 |
| `quiz.py` | 개별 퀴즈의 문제, 선택지, 정답 관리 |
| `quiz_game.py` | 메뉴, 퀴즈 진행, 점수 계산 및 파일 입출력 |
| `state.json` | 퀴즈 목록과 최고 점수 저장 |
| `.gitignore` | Git 추적 제외 파일 설정 |
| `README.md` | 프로젝트 설명 및 실행 방법 |
| `docs/screenshots/` | 프로그램 실행 결과 캡처 저장 위치 |

### 클래스 구성

**Quiz 클래스**

개별 퀴즈의 문제, 선택지, 정답을 관리한다.

- `displayQuiz()` : 문제와 선택지 출력
- `checkAnswer()` : 사용자 정답 확인
- Getter 메서드 : 문제 정보 반환

**QuizGame 클래스**

게임 전체의 진행과 데이터 관리를 담당한다.

- `showMenu()`, `startGame()` : 메뉴 출력 및 게임 실행
- `playQuiz()` : 퀴즈 출제와 점수 계산
- `addQuiz()`, `deleteQuiz()` : 퀴즈 등록 및 삭제
- `showQuizList()`, `showScore()` : 퀴즈 목록과 점수 확인
- `readNumber()`, `readText()` : 사용자 입력 처리
- `saveData()`, `loadData()` : JSON 데이터 저장 및 불러오기
- `setDefaultQuizzes()` : 기본 퀴즈 생성

## 6. 데이터 파일 설명

퀴즈 정보와 최고 점수는 프로젝트 루트의 `state.json`에 UTF-8 인코딩으로 저장한다.

### JSON 데이터 구조

```json
{
    "quizzes": [
        {
            "question": "대한민국의 국화는 무엇일까?",
            "choices": [
                "장미",
                "무궁화",
                "개나리",
                "진달래"
            ],
            "answer": 2
        }
    ],
    "best_score": 0,
    "has_played": false
}
```

| 필드 | 설명 |
|---|---|
| `quizzes` | 등록된 퀴즈 목록 |
| `question` | 문제 내용 |
| `choices` | 선택지 4개 |
| `answer` | 정답 번호 (1~4) |
| `best_score` | 최고 점수 (0~100) |
| `has_played` | 퀴즈 진행 여부 |

프로그램 시작 시 `loadData()`가 저장된 데이터를 불러온다.

파일이 없으면 기본 퀴즈 7개를 생성하며, 퀴즈 추가·삭제 또는 게임 완료 시 `saveData()`를 통해 변경된 데이터를 저장한다.

이미 저장된 파일이 있는 경우에는 코드에 작성된 기본 퀴즈보다 저장된 데이터를 우선 사용한다.
